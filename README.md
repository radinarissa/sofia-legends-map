# Легендите на София

Проект по Уеб дизайн на React. Интерактивна карта на градските легенди на София.

## Функционалности
- Карта с легенди и филтри (категория, квартал, епоха, страшност, търсене)
- Детайлна страница за всяка легенда
- Регистрация и вход
- Коментари и оценки
- Любими легенди
- Предложения на нови легенди с одобрение от администратор
- Тематични „нощни разходки“ по карта
- Легенда на деня и случайна легенда
- Тъмен режим
- Групиране на маркерите

## Технологии
- **Клиент:** React, Vite, React Router, React Leaflet, Axios
- **Сървър:** Node.js, Express, MongoDB, Mongoose, JWT

## Структура
- `client/` – React приложението
- `server/` – Express API
